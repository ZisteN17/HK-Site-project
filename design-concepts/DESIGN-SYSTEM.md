# Почерк ХК КГАСУ — дизайн-система

Единый визуальный язык сайта. Эталон — `concept-9-immersive-v2.html`.
Каждая страница строится по этим правилам, чтобы всё выглядело как один сайт.

> **ЗАКРЕПЛЕНО (2026-07-17):** главный акцент — ЗОЛОТО (бордо вторым). Слоган в геро — «Строим будущее». Тёмная тема. Фото только цветные.

## 1. Настроение
Тёмный, кинематографичный, премиальный. Не новостной портал — иммерсивный опыт.
Много крупной типографики, фото на весь экран, движение. Ощущение силы и скорости.

## 2. Цвета (токены)
```
--black:      #09090B   /* основной фон */
--panel:      #101013   /* секции-подложки */
--panel-2:    #15151A   /* карточки, ховер */
--gold:       #C9A24B   /* главный акцент: цифры, линии, кнопки, ссылки */
--gold-bright:#EAC978   /* яркое золото для мелких деталей */
--bordeaux:   #8E1B2B   /* фирменный бордо: CTA-баннеры, подсветка */
--red:        #D81E33   /* live/срочное: точка матча, теги */
--white:      #F5F3EE   /* текст, тёплый белый (не чистый #FFF) */
--dim:        #84858D   /* второстепенный текст, подписи */
```
Правило: золото — «драгоценный» акцент, не заливать им большие площади. Бордо — только для CTA и подсветок.

## 3. Типографика
- **Дисплей — Bebas Neue** (высокий, узкий, капс). Заголовки, цифры, кнопки, всё крупное. Огромные размеры (до 15rem в герое), line-height 0.8–0.9, лёгкий letter-spacing.
- **Текст — Manrope** (400–800). Абзацы, подписи, навигация, мелкий UI.
- Правило: Bebas = «голос», Manrope = «шёпот». Не набирать абзацы капсом.

## 4. Движение (обязательная часть почерка)
- **Появление при скролле** — блоки выезжают снизу с fade (`.reveal` + IntersectionObserver).
- **Ken Burns** — фото в геро медленно зумится (18s).
- **Счётчик цифр** — статистика накручивается от 0 при попадании в экран.
- **Живой таймер** — обратный отсчёт до матча тикает в реальном времени.
- **Бегущая строка** (ticker) — золотая, крутит матч/счёт/статус.
- **Ховеры** — зум фото + золотая рамка + подсветка; подчёркивание ссылок; подъём кнопок.
- **Live-точка** — красная, пульсирует.
Правило: движение служит контенту (появление, реакция на действие), а не ради украшательства.

## 5. Компоненты
- **Кнопка основная:** золотой фон, чёрный текст Bebas, подъём при ховере.
- **Кнопка-контур:** прозрачная, золотая рамка → заливается золотом при ховере.
- **CTA-баннер:** бордовый градиент, огромный заголовок, белая кнопка.
- **Карточка (игрок/новость):** тёмная, фото цветное (НИКОГДА не ч/б), при ховере — зум + золотая рамка + инфо выезжает снизу.
- **Заголовок секции:** золотой eyebrow (Bebas, letter-spacing) + огромный H2 Bebas.
- **Статы:** сетка с 2px-зазором на светлой подложке, крупные золотые цифры.
- **Шапка:** прозрачная поверх геро → затемняется с blur при скролле.

## 6. Фото
- Всегда **цветные, живые**. Ч/б запрещён (выглядит «мемориально»).
- Полноэкранные в героях, с тёмным градиент-вейлом слева/снизу для читаемости текста.
- Золотое radial-свечение как атмосфера.

## 7. Раскладка
- max-width контента 1300px, боковые отступы 44px (24px на мобиле).
- Секции чередуют фоны (black ↔ panel).
- Щедрые вертикальные отступы (100–120px между секциями).
- Мобильная версия: сетки схлопываются (6→3, 4→2, 2→1), боковые надписи прячутся.

## 8. Подпись бренда (что делает сайт «нашим»)
1. Гигантский полупрозрачный водяной знак-эмблема за заголовком геро.
2. Вертикальная золотая надпись сбоку «HC KSUAE · KAZAN».
3. Кинетическая огромная типографика с золотым контуром на втором слове.
4. Золотая бегущая строка.
